# 상대 캐릭터 대화 프롬프트 (Characters Final v3)

## 들어 있는 것
- `common-system.txt`, `character-prompts.json`, `response-schema.json`: PersonaWorld_Characters_Final_v3에서 그대로 복사한 원본.
- `profiles.json`: 설정집의 **공개 층**(이름·나이·역할·기본 관계·취향·공개 소개)만 정리. 인물 ID와 앱 `people[]` 순서(=저장된 대화의 character 번호)를 연결한다.
- `prompt.ts`: 위 자료로 대화 입력(system + 최근 대화)을 만들고, 응답이 스키마·공통 규칙에 맞는지 확인하는 함수.

## 지키는 규칙
- 말투는 의도·리듬·직접성·유머·감정 반응으로만 설명한다. 예문·캐치프레이즈·고정 인사말을 입력에 넣지 않는다.
- 설정집의 작가용 내용(결점·두려움·숨은 정보·서사 진행·미래 사건)은 이 공개 저장소에 두지 않고 입력에도 넣지 않는다. 실제로 일어난 사건만 `revealedFacts`로 넘긴다.
- `voice_direction`은 앞으로의 음성 연출 지침으로만 보관하며 텍스트 입력과 현재 음성 재생에 쓰지 않는다.
- 학습 도움 기본값은 `light`, 수준 기본값은 `B1`. 교정 카드는 대사와 분리하고, 문법·발음으로 관계 점수를 바꾸지 않는다.

## 적용 상태
- 앱 화면: 캐릭터 소개 문구·역할 줄을 설정집 공개 소개로 바꾸고, 소개의 대표 문장(캐치프레이즈)을 뺐다.
- 대화: 앱에 아직 AI API가 없어 이 프롬프트는 **연결되지 않았다**. 대화 화면은 여전히 체험용 임시 답을 쓴다. 서버 측 API 연결(비밀키는 서버에만)은 별도 작업이다.
- 확인: `npm run test:characters`
